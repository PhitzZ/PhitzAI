# PhitzAI
PhitzAI is an integrated AI that runs on Linux without the need for an API key. Designed to be fast, simple, and hassle-free, it allows you to read and analyze files directly from the terminal, save outputs to your device, and generate images.

---

# How to install?
```
curl -sSL https://raw.githubusercontent.com/PhitzZ/PhitzAI/main/install | bash -s /usr/local/bin
```

# How to run?
```
phitzai
```

# Features
**Reading file:**
```
read /my/path/script.py
```
**Analyze file:**
```
analyze /my/path/test.txt
```
**Generate Image:**
```
generate an image of $IMAGE
create an image of $IMAGE
generate photo of $Photo

$Any command related to generating image.
```

**More tools:**
```
/quit     - Exit program  
/clear    - Reset conversation  
/help     - Show this menu
/save     - Save conversation to file  
/settings - Change settings  
/aboutme
```
